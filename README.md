# 🔱 ತಂತ್ರಾಲೋಕ | Tantrāloka

### ಅಭಿನವಗುಪ್ತಾಚಾರ್ಯ ವಿರಚಿತ ತ್ರಿಕಶೈವದರ್ಶನ ಮಹಾಗ್ರಂಥ
