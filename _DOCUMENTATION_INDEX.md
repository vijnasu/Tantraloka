## 💡 Key Information

### What is Tantraloka?
A classical Sanskrit philosophical text on Kashmir Shaivism written by Abhinavagupta. This project digitizes and translates it into Kannada with detailed commentaries.

### Why This Project?
- Preserve ancient wisdom in digital format
- Make classical philosophy accessible to modern readers
- Support Kannada language community
- Enable collaborative translation efforts

## 🔄 Quick Command Reference

```bash
# View the website (NOW RUNNING)
curl http://localhost:8000/Tantraloka/

# Rebuild the site
cd /workspaces/Tantraloka && jekyll build

# Start web server (if stopped)
cd /workspaces/Tantraloka/_site && python3 -m http.server 8000 &

# Check if server is running
lsof -i :8000

# Stop the server
kill $(lsof -t -i :8000)

# Deploy to GitHub
git add . && git commit -m "Deploy Tantraloka" && git push
```
