## 🚀 Quick Start

### View the Site (Now)
```bash
# Open in browser
curl http://localhost:8000/Tantraloka/

# Or visit in web browser
http://localhost:8000/Tantraloka/
```

### Rebuild Site
```bash
cd /workspaces/Tantraloka
jekyll build
```

### Deploy to GitHub Pages
```bash
git add .
git commit -m "Deploy Tantraloka site"
git push origin main
# Site automatically builds and deploys
# Access at: https://vijnasu.github.io/Tantraloka/
```

### Stop the Server (if needed)
```bash
kill $(lsof -t -i :8000)
```

### Restart the Server
```bash
cd /workspaces/Tantraloka/_site
python3 -m http.server 8000 > /tmp/server.log 2>&1 &
```
